# ZOA-zo-friends-codex-pet
ZOA：一只适用于 Codex 的灰色毛绒猫桌宠，支持待机、工作、等待、失败、检查等动画状态，以及 16 个视线方向。ZOA is a gray plush cat companion for Codex, featuring idle, working, waiting, failure, review animations, and 16 look directions.
# ZOA



## 中文

ZOA 是一只适用于 Codex 的灰色毛绒猫桌宠，陪伴你进行日常工作。它支持待机、工作、等待、失败、检查、挥手和跳跃等动画，并支持 16 个视线方向。

### 功能

- 待机、工作中、等待输入、检查结果和失败反馈动画
- 挥手与跳跃动画
- 16 个视线方向
- Codex 桌宠 v2 精灵表格式

### 安装

将整个 `ZOA` 文件夹复制到：

```text
C:\Users\你的用户名\.codex\pets
```

目录结构：

```text
ZOA/
├── pet.json
├── spritesheet.webp

```

安装后重启 Codex，在桌宠设置中选择 **ZOA**。

## English

ZOA is a gray plush cat companion for Codex. It includes idle, working, waiting, failure, review, waving, and jumping animations, along with 16 look directions.

### Features

- Idle, working, waiting, review, and failure animations
- Waving and jumping animations
- 16 look directions
- Compatible with the Codex v2 pet spritesheet format

### Installation

Copy the entire `ZOA` folder to:

```text
C:\Users\YourID\.codex\pets
```

Directory structure:

```text
ZOA/
├── pet.json
├── spritesheet.webp

```

Restart Codex, then select **ZOA** from the desktop pet settings.

## 한국어

ZOA는 Codex에서 사용할 수 있는 회색 봉제 고양이 데스크톱 펫입니다. 대기, 작업, 입력 대기, 실패, 검토, 손 흔들기, 점프 애니메이션과 16가지 시선 방향을 지원합니다.

- Codex v2 펫 스프라이트 시트 형식 지원
